**Gerelateerde jobs:** U11 (Prettige interface), U9 (Tool werkt gewoon op mijn OS)

---

## Must

- [ ] Splash screen als eerste scherm bij opstarten — toont "CEDA Store" met versienummer
- [ ] Animatie via Harmonica (physics-based spring) — pulse of reveal effect geïnspireerd op Npuls vormentaal
- [ ] Muisklik support via `tea.WithMouseCellMotion()` — klik om splash te skippen / door versies te navigeren
- [ ] Vaste minimale grootte voor splash — layout breekt niet op kleine terminals (bouwt voort op v0.2.0 resize handling)
- [ ] Verschillende splash-varianten om doorheen te navigeren (pijltjestoetsen + muisklik)
- [ ] ADR `docs/adr/003-splash-libraries.md` — vastleggen welke libraries / technieken gekozen zijn voor animatie en layout

## Nice-to-have

- [ ] Automatisch doorgaan naar menu na X seconden (instelbaar)
