# v0.2.0 — Foundation

**JTBD:** When I open CEDA Store, I want to see a consistent, branded interface that works on my terminal size, so I feel like I'm using a professional tool.

**Gerelateerde jobs:** U11 (Prettige interface), M1 (Codebase begrijpen), M2 (Snel een release maken)

---

## Must

- [ ] `internal/styles/styles.go` — alle Lip Gloss styles als package-level vars, gebaseerd op Npuls design tokens
  - Kleurpalet: oranje `#DD784B`, blauw `#3D68EC`, groen `#00AF81`, geel `#F4D74B`, gray-900 `#111827`
  - Goedgekeurde combinaties: zwart + oranje, zwart + blauw, zwart + groen
  - Borders: rounded (Lip Gloss `lipgloss.RoundedBorder()`)
- [ ] "CEDA Store" als vaste titel zichtbaar in de root view (header component)
- [ ] Minimale terminalgrootte instellen — waarschuwing tonen als terminal te klein is (`tea.WindowSizeMsg`)
- [ ] Window resize handling — `tea.WindowSizeMsg` afvangen in root model
- [ ] Graceful exit — `ctrl+c` en `q` werken altijd, ook midden in een operatie
- [ ] Build naar executable via GoReleaser — cross-platform (Windows, Mac, Linux) binaries als output

## Nice-to-have

- [ ] Globale help overlay (`?`) met keybindings overzicht
- [ ] Content zone met min/max breedte — onder minWidth floor de layout (breekt niet), boven maxWidth centreert de content (macOS Settings gevoel). Echte OS window constraints zijn niet mogelijk vanuit een TUI app zonder native wrapper.
- [ ] Status bar onderaan — moderne balk met: versienummer links, update-status rechts
- [ ] Auto-update check — bij opstarten GitHub Releases API aanroepen (async, met timeout), nieuwere versie tonen in status bar
- [ ] In-app download + herstart — juiste binary downloaden voor huidig OS/arch, huidig binary vervangen, process herstarten
